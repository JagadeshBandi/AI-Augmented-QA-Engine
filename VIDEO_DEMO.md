## Recording Instructions

### Equipment Setup
1. **Screen Resolution**: 1920x1080 (Full HD)
2. **Audio**: Clear microphone or professional voiceover
3. **Lighting**: Bright, professional environment
4. **Background**: Clean, uncluttered workspace

### Recording Tools

#### Option 1: Loom (Recommended)
```bash
# Install Loom desktop app
# Start recording with "Screen + Camera" mode
# Position camera in upper right corner
# Record at 1080p quality
```

#### Option 2: OBS Studio
```bash
# Install OBS Studio
# Configure screen recording (1920x1080)
- Add webcam overlay (top-right corner)
- Set audio input to professional microphone
- Record at 30fps, 1080p
```

#### Option 3: QuickTime (Mac)
```bash
# Use QuickTime Player
- File > New Screen Recording
- Include microphone input
- Record full screen
```

### Recording Tips
- **Practice**: Do 2-3 practice runs before final recording
- **Pacing**: Speak clearly and at moderate pace
- **Energy**: Show enthusiasm for the technology
- **Professional**: Maintain professional demeanor throughout
